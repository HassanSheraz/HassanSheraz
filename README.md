## Research and selected projects

### RNA Motif Analysis and Generative AI — Hou Bioinformatics Lab, SLU

Worked with Dr. Jie Hou on RNA analysis tools, including the autoRNAMotifs / MotifAnalysis research workflow. My contribution covered analysis functionality as well as the application researchers used to explore the results.

- Developed Python/Streamlit workflows for PDB-based structural data, RNA motif inspection, and structural exploration.
- Built interactive research dashboards and 3D molecular views to help researchers examine structures and analysis outputs.
- Integrated generative AI and LLM-assisted features to summarize findings and support interpretation of structural patterns.
- Brought research analysis features into a browser-based application and deployed the tool on Hugging Face.

*Lab research project; source code is private.*

### Pyramid Learning — Federated Learning Client Selection

My M.S. capstone explored how client selection affects federated learning when participants have different data distributions and resources.

- Built a PyTorch/FedAvg experiment pipeline using CIFAR-10 with non-IID data partitions and 100 simulated clients.
- Implemented the partitioning, training simulation, configurable client selectors, experiment logging, and result visualization.
- Compared Random, Oort-style, DivFL, and FairFL selection, including FairFL weight-ablation experiments.
- Studied model accuracy, participation fairness, client diversity, training efficiency, and resource/energy-use estimates.
- Prepared comparison plots, experiment reports, and a capstone poster explaining the trade-offs between selection methods.

The project used PyramidFL research and reference code as a foundation. My work focused on the comparison pipeline, selection experiments, and analysis.

*Private capstone project.*
